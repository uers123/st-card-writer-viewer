# ST Card Writer Viewer

SillyTavern third-party extension for viewing and editing worldbook cards generated by ST Card Writer.

## Install

Install this repository from SillyTavern with the URL:

```text
https://github.com/uers123/st-card-writer-viewer.git
```

Then restart SillyTavern and open **Worldbook Card** from the extensions menu.

## Activation

This extension activates only for cards containing both `data.character_book` and `data.extensions.st_card_writer` metadata. It provides top-drop card rendering, grouped entries, keyword triggers, NPC/item editing, story-state preview, and deep-role prompt injection.

No model API key is stored here.
